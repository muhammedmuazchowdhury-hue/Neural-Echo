# 🎙️ Neural Echo — AssemblyAI Voice Prototype

**Neural Echo** is an AI-powered voice intelligence prototype built for the Lablab.ai hackathon. It leverages the **AssemblyAI API** and **Streamlit** to process audio files seamlessly and deliver accurate, real-time speech-to-text transcriptions across multiple languages.

### ✨ Key Features
- **Accurate Speech-to-Text:** Converts complex speech and audio files into precise text using AssemblyAI's advanced transcription models.
- **Multi-Language Support:** Seamlessly handles diverse spoken languages (including Arabic, English, and more).
- **Streamlined Workflow:** Simple file upload interface with built-in audio playback.
- **Secure Architecture:** Built with Streamlit Secrets management to ensure zero exposure of private API credentials.

### 🛠️ Tech Stack
- **Transcription Engine:** AssemblyAI Python SDK
- **Frontend & UI:** Streamlit Framework
